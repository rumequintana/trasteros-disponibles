# Trasteros disponibles

Plano interactivo con los trasteros a la venta en planta sótano.
Los trasteros disponibles aparecen en verde y el resto en gris.
Pulsa un trastero en el plano o en el listado para ver su ficha con superficies y precio.

Web: abre `index.html`, o la dirección de GitHub Pages de este repositorio.
